# Frontend · Agente Correo (Angular 22)

Se inicializa en la épica **E0.4** con `/orquestar E0.4`. Convenciones y sistema de diseño Viamatica en `docs/06-frontend-angular.md` y en el skill `.claude/skills/angular-viamatica`.

Arranque previsto:
```
cd frontend
npx @angular/cli@22 new panel --standalone --style=scss --routing --ssr=false --skip-git --directory .
npm i @angular/material@22 @angular/cdk@22 @ngrx/signals@22 echarts@6 ngx-echarts@22 tailwindcss@4 @tailwindcss/postcss
npm start
```
